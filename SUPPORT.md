# Support

Myna Player is an open-source, pre-1.0 project maintained on a best-effort basis.

- **Questions and ideas:** use GitHub Discussions.
- **Reproducible bugs:** open a bug report.
- **Feature proposals:** open a feature request or discussion.
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not create a public issue.

Before requesting help, include the operating system, application version or commit, relevant runtime/model status, and sanitized diagnostic output. Do not upload copyrighted media, transcripts containing private information, or API keys.
